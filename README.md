# StudyNest
🌷 StudyNest – Empty, Loading & Error States

UI/UX Design Project

📌 Project Overview

StudyNest is a simple student productivity app concept designed to demonstrate three important UI states: Empty, Loading and Error.

The main goal of this project is to understand how an app communicates with users when content is unavailable, loading or when something goes wrong.

📱 Screens Designed

This project includes 3 app screens:

1. Dashboard
   
   - Empty State
   - Loading State
   - Error State

2. My Tasks
   
   - Empty State
   - Loading State
   - Error State

3. My Notes
   
   - Empty State
   - Loading State
   - Error State

Total: 9 UI frames.

🎨 Design Approach

- Minimal and clean interface.
- Soft lavender and white colour palette.
- Rounded cards and simple icons.
- Consistent typography and spacing.
- Friendly messages and clear action buttons.

💡 What I Learned

Through this project, I learned how to design different UI states and why they are important for user experience.

I also understood how clear messages, loading indicators and retry actions can make an application easier to understand and use.

🎯 Project Objective

To create a simple and user-friendly interface that provides a clear experience even when the app has no content, is loading or encounters an error.
